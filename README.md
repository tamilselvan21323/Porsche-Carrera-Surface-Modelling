# Porsche Carrera - SOLIDWORKS Surface Modeling

A highly detailed 3D surface model of a Porsche Carrera created entirely within **SOLIDWORKS 2021**. This project focuses on high-quality Class-A surfacing, curvature continuity, and aesthetic design.

## 📊 Design & Continuity Analysis

### Curvature Continuous Surfaces
The body uses advanced lofting and filling techniques to ensure smooth light transitions across panels.
!(curvature.png)

### Zebra Stripe Inspection
Zebra stripe evaluation shows flawless reflection lines and tangency across the hood, roof, and fenders.
